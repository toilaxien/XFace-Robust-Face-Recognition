# Checkpoints

Large model checkpoints are excluded from Git.

Recommended names:

- `xface_best.pth`
- `arcface_best.pth`
- `cosface_best.pth`
- `adaface_best.pth`
- `magface_best.pth`
- `hamface_best.pth`

Use GitHub Releases, Hugging Face Hub, Kaggle Dataset, Google Drive, or Git LFS for large artifacts.
